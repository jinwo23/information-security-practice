# Electronic Dean's Office

## Опис

REST API на FastAPI + Docker + Nginx HTTPS (Практична №9)

## Запуск

docker compose up --build

## Доступ

https://localhost  
https://localhost/docs  

Або напряму до API:

http://localhost:8000  
http://localhost:8000/docs
